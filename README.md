# Тренажёр по силлогистике

Тренажёр по категорическим силлогизмам. Одна HTML-страница без зависимостей, открывается в любом браузере.

**Вкладка «Силлогизм».** Порождается случайный силлогизм. Нужно определить меньший, средний и больший термины, фигуру, модус и правильность силлогизма. Если он неправильный, нужно указать, какие общие правила нарушены. После проверки показывается разбор: распределённость терминов и проверка по каждому правилу.

**Вкладка «Энтимема».** Дано рассуждение с пропущенной посылкой или заключением. Нужно выбрать все суждения, которые превращают его в правильный силлогизм, или ответить, что энтимему восстановить нельзя.

Все термины считаются непустыми, поэтому правильными признаются 24 модуса, включая ослабленные.
